Drop photographs in this folder.

Two files the site expects by name:

  og-lumi.jpg    1200x630. The image that appears when the site is shared on
                 WhatsApp, Instagram or in a text message. Use one strong
                 food shot with the logo bottom-left. Nothing else works
                 harder for bookings than this one file.

  favicon.svg    Already here - the sunburst on cream. Replace only if the
                 logo changes.

Everywhere else, the placeholder blocks on the site describe the shot that
belongs there. Save photos at no more than 2000px on the long edge and run
them through squoosh.app before uploading, or the site will be slow.
